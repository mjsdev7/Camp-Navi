# Camp-Navi

Camp-Navi is a full-stack campground listing web application that allows users to browse, create, update, and delete camping locations.

This project was built as a personal full-stack web development project using Node.js, Express, and MongoDB, focusing on backend development, database design, and RESTful routing.

---

## Features

- Full CRUD functionality (Create, Read, Update, Delete campgrounds)
- MongoDB + Mongoose database integration
- Server-side rendering with EJS
- Form handling and validation
- Error handling for routes and database operations
- Organized MVC-style structure
- Real campground data across Japan
- Clean UI using Bootstrap

---

## Project Focus

Camp-Navi uses real campground locations instead of placeholder data, making it feel like a real-world travel application. Each listing includes realistic titles, locations, pricing, and descriptions.
