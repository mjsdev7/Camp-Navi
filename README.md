# Camp-Navi

A full-stack campground listing web application that allows users to browse, create, and manage camping locations.

Camp-Navi was built as a personal project to practice full-stack web development using Node.js, Express, and MongoDB. The application focuses on real-world campground data and a clean CRUD-based architecture.

---

## Project Overview

Camp-Navi is a campground directory platform where users can explore and manage camping locations across Japan.

The project was designed to simulate a real-world travel listing service, with an emphasis on usability, data structure, and backend development.

---

## Key Features

- Full CRUD functionality for campgrounds  
- MongoDB database integration with Mongoose  
- Server-side rendering using EJS templates  
- Form handling and validation  
- Error handling for routes and database operations  
- Real-world campground data (not placeholder content)  
- Clean and structured UI layout  

---

## Real-World Focus

Unlike basic demo projects, Camp-Navi uses real campground locations across Japan, including:
- Accurate titles and descriptions  
- Real geographic locations  
- Practical pricing structure  

This makes the project closer to a production-style travel application rather than a tutorial demo.

---

## Tech Stack

- Node.js  
- Express.js  
- MongoDB + Mongoose  
- EJS
